研究与安全

OpenAI 在可解释性、对齐与红队方面持续探索：通过 RLHF、偏见缓解、系统提示与审计管线，降低风险并提升稳健性。

对齐（Alignment）
RLHF、宪法式对齐、拒答与审校策略。
安全（Safety）
能力评测、红队测试、内容过滤与安全层。
系统（Systems）
训练基础设施、推理优化、可扩展性。
评测（Eval）
多维指标与公开基准协同演进。

生态与 API

工具、插件、工作流与平台
快速上手
import OpenAI from "openai";
const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

const completion = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [
    { role: "system", content: "你是可靠的助理" },
    { role: "user", content: "用一句话介绍 OpenAI" }
  ]
});
console.log(completion.choices[0].message);
